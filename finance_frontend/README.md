# FinanceApp Frontend

README chi tiết của backend và frontend đã được gộp thành một file ở root project:

```text
../README.md
```

Phần frontend trong README chính bao gồm:

- Yêu cầu trước khi chạy.
- Cách chạy React/Vite app.
- Cách frontend gọi backend qua Vite proxy.
- Luồng đăng nhập và lưu JWT.
- Các route chính.
- Lệnh `npm install`, `npm run dev`, `npm run lint`, `npm run build`.
