# FinanceApp Backend

README chi tiết của backend và frontend đã được gộp thành một file ở root project:

```text
../README.md
```

Phần backend trong README chính bao gồm:

- Kiến trúc ASP.NET Core Web API.
- Entity Framework Core và SQL Server.
- ASP.NET Identity và JWT Authentication.
- Repository Pattern, DTO, Mapper.
- API endpoints.
- Luồng hoạt động đăng nhập, portfolio, comment.
- Cách chạy backend, migration database và xử lý lỗi thường gặp.
